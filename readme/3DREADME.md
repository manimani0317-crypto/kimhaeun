### 3D / 2D 나누기 (정한 방향)

| 요소 | 방식 |
| --- | --- |
| 김하은 안내서 | 실제 코딩 (HTML/CSS 페이지 넘김) — 글이 선명하고 수정·검색이 쉽다 |
| 단추 · 바늘꽂이 · 쪽가위 · 실패 | 3D |
| 자동 줄자 | 케이스만 3D, 눈금 띠는 2D |
| 원단 스와치 · 리스트 종이 · 핀 | 2D (3D 장면 안의 사진 판) |
| 미싱 · 거울 | 3D (고개를 들었을 때만 보임) |

- 고개를 드는 움직임이 있으니 **화면 전체가 하나의 3D 장면**이어야 한다. 2D 요소도 3D 공간 안에 놓인 사진 판으로 넣는다
- 성능 원칙: 캔버스는 페이지당 하나, 삼각형 전체 30만 이하, 텍스처 1~2K, 조명 2~3개, 안 움직일 땐 다시 그리지 않기
- 거울은 실시간 반사 대신 미리 구운 이미지로
- 미싱·거울은 첫 화면이 뜬 뒤 뒤에서 불러온다

## 6. 오브젝트별 상태

### 단추 — 완료
- 코드로 만든 3D(Three.js). 이미지 파일 없이 단면 곡선을 돌려 만들어서 **아주 가볍다**
- 빨간 단추: 도톰한 테두리, 오목한 가운데, 구멍 4개
- 꽃 단추: 빨간 단추와 같은 단면에 바깥만 꽃잎 5장, 구멍 2개, 아이보리 유광
- 호버: 들리고 → 커서 쪽으로 기울고 → 살짝 돌고 → 광이 표면을 한 번 지나간다
- 다른 페이지에서도 `buttonFinal.js`를 불러 쓰면 된다
- 겪은 문제: 테두리와 가운데를 따로 만들면 경계선이 생긴다 → 한 면으로 이어지게 만들었다. 구멍이 막혀 보였던 건 바닥판 구멍이 거울처럼 뒤집혀 있었던 것

### 실패 — 거의 완료
- 참고: `references/threadSpool/`
- 검정 나무 끝판 2장, 가운데가 살짝 불룩한 실 몸통, 크림색 심, 풀린 실 한 가닥
- **눕혀 둔다.** 호버하면 앞으로 약 30° 구르고(미끄러지지 않게 거리 = 각도 × 반지름) 떼면 돌아온다
- 실 결은 레퍼런스를 보고 **직접 그린 이미지**를 입혔다. 가닥 6~14개가 한 묶음 띠로 나란히, 띠 76개가 여러 방향으로 겹쳐 뜨개실처럼 감긴 모양. 띠 끝은 서서히 사라져 다른 실 밑으로 파고든다
- 광은 죽이고 명암 대비를 높였다
- 결을 바꾸려면 `threadTexturePainter.html`을 고쳐서 연 뒤, 위쪽 링크로 두 이미지를 받아 `threadSpool/`의 같은 이름 파일과 바꾼다
- 참고: 조명 설정은 확인 페이지(`threadSpool3d.html`)에 있다. 메인 장면에 합칠 때 조명을 하나로 통일해야 한다

### 미싱 — 1차 완료
- 참고: `references/sewingMachine/` (Elna eXperience 450)
- 코드로 도형을 조립한 모델. 가운데 배치, 드래그 회전, 휠 확대
- 핸드휠을 끌면 바늘과 실채기가 따라 움직인다
- 디테일 버전: 조작 버튼·속도 슬라이더, 페이스 플레이트, 앞으로 나온 윗실, 톱니, 시접 안내선, 손잡이 등 추가
- **한계**: 다른 오브젝트가 사진급이 되면 이 미싱은 장난감처럼 보일 수 있다. 최종은 GLB 모델로 다시 만드는 게 좋다

### 바늘꽂이 — 작업 중 (막힘)
- 참고: `references/pinCushion/` — 각도별 원본 10장(`00`~`09`: 바늘과 정면, 정면, 좌우 반측면·옆면, 후면, 위, 아래, 크림 진주핀 단독)

## 7. 작업하며 알게 된 것 — 피드백 기록

`references/*/feedback/`의 캡처는 내가 작업물에 직접 표시한 수정 요청이다.

- **레퍼런스를 대충 보고 만들면 안 된다.** 정면·옆면·반측면을 각각 치수로 재서 옮겨야 한다
- 코드로 만든 무늬는 규칙적이라 가짜처럼 보인다 → 실처럼 불규칙한 재질은 **이미지를 직접 그려서** 입히는 게 낫다
- 실 결은 한 올씩 격자로 박으면 철조망처럼 보인다 → 여러 가닥을 묶은 띠가 여러 방향으로 겹쳐야 한다
- 요철(범프)을 세게 주면 라면사리처럼 보인다 → 약하게
- 3D는 **방향과 기준면 실수**가 제일 흔하다 (좌우 반전, 90° 회전 방향, 모서리 둥글림만큼 높아진 윗면 등)
- 광택을 과하게 주면 빨강이 분홍으로 뜬다

### 내가 직접 조절하고 싶을 때 — 조절판 형식

"이건 내가 직접 조절할게"라고 하면, 숫자를 말로 주고받지 말고 **확인 페이지에 조절판을 붙인다.**
기준 구현: `pinCushion/pinCushion3d.html` (E 키)

**만드는 법**
1. 모델 파일(`○○.js`)에서 조절할 값을 객체 하나로 모아 `export const` 로 내보낸다. 값마다 무슨 뜻인지 한 줄 주석
2. 모양을 만드는 부분을 함수로 묶어 `rebuild()` 로 다시 부를 수 있게 내보낸다 (바늘꽂이는 `pc.rebuild()`). 재질·텍스처는 다시 만들지 않는다 (다시 그리면 느리다)
3. 확인 페이지 오른쪽 위에 조절판을 둔다
   - 항목마다 슬라이더 + 한글 이름 + 코드 키 + 지금 값
   - 끌면 바로 반영된다 (한 프레임에 한 번만 다시 만든다)
   - 아래에 지금 값을 **코드 그대로** 보여 준다
   - `코드 복사` / `처음 값` 버튼
   - `E` 키로 숨기기·보이기 — 창이 좁으면 모델을 가린다
4. 슬라이더 범위는 지금 값이 가운데쯤 오게, 넉넉하게

**주고받는 법**
- 나는 조절판에서 맞춘 뒤 `코드 복사` 한 줄을 그대로 붙여 준다
  ```js
  export const EAR = { X: .385, Y: .625, Z: .455, TAPER: .245, TILT: .465, PX: .96, PY: .77 };
  export const BODY = { A: 1, B: .86, H: 1.425, N: 2.2 };
  ```
- 받으면 모델 파일의 같은 줄과 바꾸고, 새로고침해서 조절판이 그 값으로 시작하는지 확인한다
- 슬라이더는 파일을 바꾸지 않는다. 새로고침하면 파일에 적힌 값으로 돌아간다
- 확인 페이지는 반드시 로컬 서버 주소로 연다. 파일을 직접 열면(`file://`) 조절판 틀만 뜨고 슬라이더와 모델이 비어 있다

## 8. 실행하는 법

3D 파일은 `type="module"`이라 **파일을 더블클릭하면 안 열린다.** 로컬 서버로 띄운다.

```bash
npx serve "C:\김하은\사용중인폴더\개인 퍼스널 포폴\kimhaeun"
```

그다음 브라우저에서:
- 단추: `http://localhost:3000/assets/main/button/buttonFinal.html`
- 실패: `http://localhost:3000/assets/main/threadSpool/threadSpool3d.html`
- 바늘꽂이: `http://localhost:3000/assets/main/pinCushion/pinCushion3d.html?az=0` (`az=` 각도 고정, 0 정면 / 90·-90 옆면)
- 남산타워 줄자: `http://localhost:3000/assets/main/tapeMeasure/tapeTower3d` (E 키 곰 조절판)
- 쪽가위: `http://localhost:3000/assets/main/scissors/scissors3d`
- 미싱: `http://localhost:3000/assets/main/sewingMachine3dDetailed.html`
- 실 결 다시 그리기: `http://localhost:3000/assets/main/threadTexturePainter.html`

기술: Three.js 0.160 (CDN에서 불러옴), 설치할 라이브러리 없음.
