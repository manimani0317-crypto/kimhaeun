교체 방법

지금 보이는 릴은 코드로 그린 임시 이미지입니다. 아래 프롬프트로 PNG를 뽑아 배경을 지운 뒤, CSS 최상단 --reel 한 줄만 바꾸면 그대로 붙습니다. 나머지 코드는 손댈 필요 없습니다.

1 — 생성 프롬프트

기존 실타래·단추와 같은 조명 조건을 명시하는 게 핵심입니다. 가능하면 실타래 이미지를 레퍼런스로 함께 넣으세요.

2 — 후처리

배경 검정을 알파로 제거 → 물체 주변 검은 테두리(프린지) 정리 → 2x 해상도로 저장. 그림자는 코드가 그리므로 PNG에 그림자를 포함하지 마세요.

3 — 연결

CSS --reel: url("...") 지정. 자바스크립트가 이미지를 읽어 테이프 출구 위치와 히트영역을 자동으로 다시 계산합니다.
